# AI Fitness Tracker

An AI-powered Fitness Tracker web application that helps users monitor their health by tracking meals, daily activities, calorie intake, and fitness goals. The application uses Google Gemini AI to provide intelligent food analysis and nutritional insights for personalized fitness tracking.

## 🌐 Live Demo

🔗 **Frontend Live Demo:**  
https://ai-fitness-web-one.vercel.app/

---

## 🚀 Features

- 🔐 Secure User Authentication
- 🍽️ Food Logging and Calorie Tracking
- 🏃 Activity Tracking
- 📊 Daily Fitness Progress Monitoring
- 🤖 AI-powered Food Image Analysis using Google Gemini AI
- 🎯 Personalized Fitness Goals
- 👤 User Profile Management
- 📱 Responsive User Interface

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/khushiagarwal126/AI-Fitness-WEB.git
```

### Navigate to Project

```bash
cd AI-Fitness-WEB
```

---

## Frontend Setup

Navigate to client folder:

```bash
cd client
```

Install dependencies:

```bash
npm install
```

Run frontend:

```bash
npm run dev
```

Frontend runs on:

```text
http://localhost:5173
```

---

## Backend Setup

Navigate to server folder:

```bash
cd server
```

Install dependencies:

```bash
npm install
```

Start Strapi server:

```bash
npm run develop
```

Backend runs on:

```text
http://localhost:1337
```

---

## 🔑 Environment Variables

Create a `.env` file inside the `server` directory and configure the required environment variables.

Example:

```env
DATABASE_URL=
APP_KEYS=
API_TOKEN_SALT=
ADMIN_JWT_SECRET=
JWT_SECRET=
GEMINI_API_KEY=
```
